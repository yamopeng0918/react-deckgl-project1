# 隨機森林前三層判斷邏輯 PowerPoint 設計

## 目的

製作一頁 16:9 PowerPoint，以非技術觀眾能快速理解的方式，呈現目前已訓練隨機森林模型中一棵代表樹的前三層真實判斷規則，並清楚說明單棵樹與整座森林投票之間的關係。

這張圖用於解釋最大震度分類模型，不得暗示模型可以預測地震是否發生。

## 資料與模型來源

- 模型：`data/model/random_forest_model.joblib`
- 模型設定與結果：`data/model/random_forest_metrics.json`
- 特徵順序：
  1. `magnitude`：震級
  2. `depth_km`：深度
  3. `longitude`：經度
  4. `latitude`：緯度
  5. `month`：月份
  6. `hour`：時刻
- 分類目標：最大震度 0–7。

## 代表樹選擇

從已訓練模型的全部決策樹中選擇一棵代表樹，而不是任意使用第一棵樹。

選擇原則依序為：

1. 根節點使用森林中最常見的根節點特徵。
2. 前三層具有完整或接近完整的可視結構。
3. 優先選擇較容易向一般觀眾解釋的切分；若條件相同，使用模型中的較前序樹，確保輸出可重現。

產生器必須直接讀取現有 `.joblib` 模型並抽取真實特徵、門檻、樣本數與類別分布，不手動編造規則。

## 投影片內容

輸出為一頁 16:9 投影片，標題為：

> 隨機森林如何判斷最大震度？

主要區域顯示代表樹從根節點開始的前三層：

- 第一層：1 個根節點。
- 第二層：最多 2 個節點。
- 第三層：最多 4 個節點。
- 每個節點顯示中文特徵名稱、真實門檻、節點樣本數，以及目前占比最高的震度類別。
- 分支線標示「是（≤）」與「否（>）」。
- 若前三層內遇到葉節點，直接顯示該葉節點的預測震度，不建立虛構的後續節點。

頁面下方顯示森林投票說明：

> 這只是 200 棵樹中的一棵。每棵樹各自判斷，最後由所有樹投票決定分類結果。

另加限制說明：

> 前三層只呈現模型早期的主要切分，不代表完整模型；本模型是最大震度分類，不是地震預測。

## 視覺方向

- 使用清楚、適合簡報投影的淺色背景。
- 根節點、第二層、第三層使用由深至淺的同色系，強化閱讀順序。
- 「是」與「否」分支使用不同但色盲友善的顏色。
- 震度預測以小型醒目標籤呈現，不使用大面積警示色。
- 文字以繁體中文為主，技術欄位名稱不直接暴露給觀眾。
- 所有節點、連線與說明必須留在安全邊界內，不得重疊或裁切。

## 產物與重跑方式

預計新增：

- PowerPoint 產生器：`scripts/create_random_forest_three_level_explainer.py`
- PowerPoint：`data/model/random-forest-three-level-explainer.pptx`
- 自動化測試：`tests/test_create_random_forest_three_level_explainer.py`

產生器預設直接使用現有模型與指標檔，並以固定預設路徑輸出。重跑命令：

```powershell
python scripts/create_random_forest_three_level_explainer.py
```

## 驗證標準

- PowerPoint ZIP/OpenXML 結構完整。
- 恰好一張投影片，比例為 16:9。
- 投影片包含標題、前三層節點、真假分支、森林投票說明與限制說明。
- 節點上的特徵、門檻、樣本數和主導震度可由 `.joblib` 模型重新核對。
- 代表樹選擇演算法具決定性，相同模型重跑得到相同樹與相同投影片內容。
- 不將單棵代表樹描述成完整隨機森林。
- 完整 Python 測試、前端測試與正式版建置仍通過。
