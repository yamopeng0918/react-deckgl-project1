# Closing Report HyperFrames Design

## Goal

Create a short HyperFrames video composition that previews the final project closing-report direction for the Taiwan Earthquake Hotspot Explorer.

## Approved Direction

The user approved a combined direction:

-成果簡報型: show the project result clearly as a closing-report deliverable.
-學習歷程型: include the workflow from raw CSV data to public deployment.

## Audience

The audience may not understand programming. Copy must be simple, concrete, and focused on visible outcomes.

## Format

- One HyperFrames composition under `hyperframes/closing-report/`.
- Landscape 1920x1080.
- About 45 seconds.
- Six scenes:
  1. Cover.
  2. Project goal.
  3. Data outcome.
  4. Build process.
  5. Feature outcome.
  6. Completion summary.

## Required Content

- Project name: 台灣地震熱區探索器.
- Public URL: `https://react-deckgl-project1-kappa.vercel.app/`.
- Data range: 1995-2026.
- Source CSV count: 48.
- Exported records: 16,691.
- Core workflow: CSV -> Python -> React -> deck.gl -> Vercel.
- Core features: heatmap, earthquake points, year range, magnitude range, click summaries, yearly chart.

## Visual Direction

Use a clean data-dashboard style:

- Dark navy background.
- Cyan and amber highlights.
- Large readable numbers.
- Simple Taiwan-map inspired visual marks.
- Card-based scenes with minimal text.

## Non-Goals

- No voiceover yet.
- No complex 3D.
- No final polished marketing animation.
- No dependency on live website screenshots for the first preview.
